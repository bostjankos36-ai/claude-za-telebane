description: Shrani spremembe na GitHub z razumljivim opisom
---

Shrani trenutne spremembe na GitHub.

1. Pokaži mi kratek seznam, katere datoteke so se spremenile.
2. Napiši kratek opis spremembe v slovenščini (en stavek).
3. Naredi commit s tem opisom in ga potisni (push) na GitHub.
4. Sporoči mi: "Shranjeno ✅" in kaj je bilo shranjeno.

Če kaj ne uspe, mi preprosto razloži, kaj je šlo narobe.
