# Preveri kodo

Ko preverjaš kodo, naredi tole po vrsti:

1. **Preberi** datoteko, ki se je spremenila.
2. **Zaženi** jo, če se da (npr. odpri stran ali poženi skripto).
3. **Preizkusi** glavno funkcijo — tisto, zaradi katere stvar obstaja.
4. **Poročaj** v treh vrsticah:
   - Kaj si preizkusil
   - Ali dela (DA / NE)
   - Če ne dela: kaj je narobe in predlog popravka
